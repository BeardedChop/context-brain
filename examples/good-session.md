# Good Session Example

```text
Read .context/packed-context.md first.

Task:
Add email auth to the dashboard app.

Constraints:
- keep existing dashboard routes unchanged
- use Supabase, not Clerk
- keep auth helpers in lib/auth
- do not add billing or onboarding yet

Before editing:
1. summarize the current architecture
2. name the files you expect to change
3. give me the smallest safe plan
```

Why this works:

- the task has a boundary
- the AI sees decisions before changing code
- the architecture has a place for the new work
- the assistant plans before editing
