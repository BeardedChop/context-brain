# Context Hygiene

## Keep
- active goal
- current architecture
- important constraints
- open decisions
- recent changes that still matter
- current next action

## Drop
- stale brainstorms
- repeated explanations
- solved debugging trails
- old implementation attempts that are no longer relevant
- large logs, generated output, and old failed paths

## Rule of thumb
If a future session does not need it to make the next good decision, cut it.

## Good packed context
- short enough to skim
- clear enough to plan from
- honest about unfinished work
- specific about constraints
- boring about architecture
