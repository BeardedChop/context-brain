# Web Template

Use this when the project is a browser app or full-stack web product.

## First session

1. Fill in `docs/CONTEXT.md` with the product goal.
2. Fill in `docs/ARCHITECTURE.md` with the routes, components, and data flow.
3. Add any already-made choices to `docs/DECISIONS.md`.
4. Run `bash scripts/context-pack.sh` after copying the packer into `scripts/`.
5. Paste `.context/packed-context.md` into your AI coding tool before asking for code.

Suggested folders:
- `app/` or `src/`
- `components/`
- `lib/`
- `docs/`
- `context/`
- `scripts/`

## Good first task

Ship one user flow end to end before adding more screens.
