# CONTEXT

## Project goal
Help beginner AI-assisted developers start each coding session with a small, useful project brain instead of re-explaining context from scratch.

## Current state
The repo contains a lightweight documentation system, session-start/session-end workflows, a context packing script, copy/paste prompts, and starter templates for web, API, and CLI projects.

## Current priority
Make the first-run experience obvious: clone/copy, fill in the docs, run the packer, paste the packed context into an AI coding tool, and get a better session immediately.

## Constraints
- keep the system tiny enough that beginners will actually use it
- avoid turning this into a full project management framework
- make every file explain why it exists
- protect internal launch notes from public releases

## Open questions
- Should `context-brain` become its own public repo or merge into the broader `repo-brain` ecosystem?
- Which stack-specific premium kit should come first: Next.js, Python, or React Native?
